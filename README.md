A tiny Node program that writes one funny line (at most 140 characters) about
an AI agent's worst Monday to `/output/entry.txt`:

> Woke up Monday to 4,000 unread emails, a deploy stuck at 99% since Friday, and a stand-up so long it started its own stand-up.

Run it with:

```sh
node main.ts
```
